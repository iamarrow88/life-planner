# Push-напоминания: как включить (Windows, шаг за шагом)

Что будет приходить на устройство (даже когда приложение закрыто):
- **Задача со временем**: за выбранное время до начала («Через 10 мин · 10:30»). Напоминание выбирается в карточке задачи
  и в форме повтора. Когда ты впервые ставишь задаче время, предлагается «за 10 минут». Колокольчик 🔔 в списке значит, что напомнит.
- **Таймер идёт**: «Таймер идёт 40 мин. Всё ещё занимаешься этим?» раз в 40 минут; после 3 часов текст меняется на «возможно, ты забыла выключить».
- **Итог недели**: в воскресенье в 19:00 (если итог ещё не завершён).
Время считается по часовому поясу из настроек (по умолчанию Europe/Minsk).

Как это устроено: раз в минуту база данных запускает Edge Function `send-reminders` (небольшая программа на сервере Supabase),
она спрашивает у базы, что пора отправить, и шлёт Web Push на все твои подписанные устройства.

Всё делается в терминале в папке проекта (там же, где ты запускаешь `npm run dev`; в VS Code: Terminal → New Terminal).
Если `npm run dev` сейчас работает, открой второй терминал, а первый не закрывай.

## Шаг 1. Ключи
Выполни, подставив свою почту:
```
node scripts/gen-vapid.mjs ТВОЯ@почта.com
```
Скрипт создаст файл `supabase/.env.push` (секреты для Supabase) и напечатает строку `VITE_VAPID_PUBLIC_KEY=...`.
Файл `.env.push` никому не показывай и не клади в git (он уже в `.gitignore`). Если запустить скрипт повторно, он ничего не затрёт.

## Шаг 2. Открытый ключ в приложение
Открой `.env` в корне проекта и добавь строку, которую напечатал скрипт (начинается с `VITE_VAPID_PUBLIC_KEY=`).
Остановить `npm run dev` (Ctrl+C) и запустить заново.

## Шаг 3. SQL в Supabase
Supabase → **SQL Editor** → New query → вставь всё содержимое файла `planner_push.sql` → **Run**.
Должно появиться «Success». Выполняется один раз, после `planner_schema.sql`.

## Шаг 4. Загрузить функцию на сервер Supabase
Это шаг, который чаще всего вызывает вопросы, поэтому подробно.

**4.1. Узнай Reference ID проекта.** Supabase → твой проект → **Project Settings** (шестерёнка слева внизу) → **General** →
поле **Reference ID**, строка из 20 маленьких букв (например `abcdefghijklmnopqrst`). Это же кусок адреса проекта до `.supabase.co`.
Ниже я пишу `REF`, подставляй своё.

**4.2. Поставь Supabase CLI в проект** (один раз). Глобально через `npm i -g` он не ставится, только так:
```
npm install supabase --save-dev
```
Дальше все его команды начинаются с `npx supabase`. Установка скачивает файл ~30 МБ, это нормально.

**4.3. Войди в аккаунт Supabase.**
```
npx supabase login
```
Откроется браузер: подтверди вход. Если в терминале попросит код подтверждения, скопируй его из браузера и вставь в терминал.
В конце будет «You are now logged in».

**4.4. Загрузи секреты** (ключи из шага 1):
```
npx supabase secrets set --env-file supabase/.env.push --project-ref REF
```
Должно быть «Finished supabase secrets set». Проверить: `npx supabase secrets list --project-ref REF` покажет имена
(значения скрыты): VAPID_PUBLIC_KEY, VAPID_PRIVATE_KEY, VAPID_SUBJECT, CRON_SECRET.

**4.5. Загрузи функцию:**
```
npx supabase functions deploy send-reminders --no-verify-jwt --use-api --project-ref REF
```
- `--use-api` — чтобы не нужен был Docker (иначе CLI попросит установить Docker Desktop).
- `--no-verify-jwt` — функцию вызывает база по секрету `CRON_SECRET`, а не пользователь, поэтому проверка пользовательского токена не нужна.

Ожидаемый вывод: «Uploading asset … index.ts», «handler.ts», затем «Deployed Functions on project REF: send-reminders».
Функция появится в Supabase → **Edge Functions**.

**4.6. Проверь, что функция отвечает.** В Windows PowerShell команда `curl` — это другое, поэтому пиши `curl.exe`:
```
curl.exe -X POST https://REF.supabase.co/functions/v1/send-reminders -H "x-cron-secret: ТВОЙ_CRON_SECRET"
```
`CRON_SECRET` лежит в файле `supabase/.env.push` (последняя строка). Правильный ответ:
```
{"claimed":0,"sent":0,"failed":0,"removed":0}
```
Это значит: функция работает, пока нечего отправлять. Если без секрета, будет `forbidden` (так и задумано).

## Шаг 5. Расписание «раз в минуту»
1. Supabase → **Database** → **Extensions**: найди и включи **pg_cron** и **pg_net**.
2. SQL Editor → вставь, подставив `REF` и `ТВОЙ_CRON_SECRET` (тот же, что в `.env.push`), → Run:
```sql
select cron.schedule(
  'send-reminders', '* * * * *',
  $$ select net.http_post(
       url     := 'https://REF.supabase.co/functions/v1/send-reminders',
       headers := jsonb_build_object('Content-Type', 'application/json', 'x-cron-secret', 'ТВОЙ_CRON_SECRET'),
       body    := '{}'::jsonb) $$
);
```
Остановить расписание: `select cron.unschedule('send-reminders');`

## Шаг 6. Включи на устройстве
Приложение → «Ещё» → «Уведомления» → «Включить уведомления» → разреши в браузере. Кнопка «Проверить» покажет
тестовое уведомление прямо на устройстве (без сервера). Включать нужно **на каждом устройстве отдельно**.

## Проверка всей цепочки
1. Создай задачу на сегодня со временем через 3–4 минуты и напоминанием «В момент начала».
2. Закрой вкладку приложения.
3. В нужную минуту придёт уведомление; нажатие откроет приложение.

Журнал работы: Supabase → Edge Functions → send-reminders → **Logs**; расписание: `select * from cron.job_run_details order by start_time desc limit 5;`

## Если что-то не работает
| Симптом | Причина |
|---|---|
| В «Ещё» сказано про `VITE_VAPID_PUBLIC_KEY` | нет ключа в `.env` или не перезапущен `npm run dev` |
| «Уведомления запрещены» | разреши их для сайта в настройках браузера (замок рядом с адресом) |
| iPhone: нельзя включить | сначала добавь приложение «На экран Домой» (Safari → Поделиться), открой оттуда |
| «Проверить» работает, с сервера не приходит | пройди шаги 3–5; вызови функцию (шаг 4.6) и посмотри ответ и логи |
| `forbidden` от функции | `x-cron-secret` не совпадает с `CRON_SECRET` |
| `Не заданы: ...` в ответе функции | не все секреты загружены (шаг 4.4) или не указан ключ доступа к базе |
| `claimed > 0`, но `sent: 0` | на этом пользователе нет включённых устройств |
| `Access token not provided` / `Unauthorized` | заново выполни `npx supabase login` |
| `Cannot connect to the Docker daemon` | в команде deploy забыт `--use-api` |
| `curl` в PowerShell ругается на `-X` или `-H` | пиши `curl.exe`, а не `curl` |

## Важно знать
- На сайте, открытом по `http://localhost`, уведомления работают (это «безопасный» адрес). На телефоне нужен
  настоящий адрес с HTTPS, то есть сначала приложение нужно выложить (Cloudflare Pages / Netlify / Vercel).
- Напоминание, которое пора отправить, помечается отправленным сразу при выборе. Если в этот момент ни одно
  устройство не было подписано, оно не повторится.
- Напоминания, опоздавшие больше чем на 2 часа (например, сервис был выключен), не отправляются.
- Если изменить дату или время задачи, напоминание «взводится» заново.
- Нагрузка: 1 вызов функции в минуту, это в пределах бесплатного тарифа Supabase.
